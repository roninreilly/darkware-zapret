**[Read in English](README.md)**

Нативное приложение в строке меню macOS для обхода DPI: экспериментальный пакетный движок и два локальных SOCKS-движка. В бете 2.0 появился пакетный режим на основе [Mac-порта Flowseal](https://github.com/Flowseal/zapret-mac-discord-youtube), безопасное управление процессами, восстановление настроек прокси и диагностика HTTPS.

**Darkware 2.0 — версия приложения.** Движок zapret2 не включён: [upstream zapret2](https://github.com/bol-van/zapret2) не поддерживает macOS. **2.0.0-beta.1 — предварительный релиз**; последняя стабильная версия остаётся 1.0.39.

## Выбор режима

| Движок | Требования | Возможности и ограничения |
| --- | --- | --- |
| Native Packet · experimental | macOS 14+, права администратора | `nfqws` через `utun`/BPF, 21 профиль Flowseal, пакетная обработка IPv4 TCP/UDP. Возможны конфликты с туннельными VPN. Эффективность, QUIC и голос Discord проверяются на конкретной сети. |
| zapret · tpws | macOS 13+ | Локальный SOCKS5 для TCP. Сам процесс прокси работает без root. |
| ByeDPI | macOS 13+ | Локальный SOCKS5 с TCP-стратегиями. UDP и голос приложений автоматически не перехватываются. |

Universal-сборки включают Apple Silicon и Intel. SOCKS действует для приложений, которые его используют. Системная настройка SOCKS **не направляет весь трафик и весь UDP** macOS в прокси. Обход DPI не предоставляет внешний VPN-сервер и не устраняет все блокировки DNS или IP.

## Установка и подключение

1. Скачай DMG из [2.0.0-beta.1](https://github.com/RoninReilly/darkware-zapret/releases/tag/v2.0.0-beta.1), открой его и перетащи **darkware zapret.app** в **Applications**. [Последняя стабильная версия](https://github.com/RoninReilly/darkware-zapret/releases/latest) доступна отдельно.
2. Запусти приложение и нажми на щит в строке меню. Если macOS блокирует неподписанную сборку, после проверки источника используй **Системные настройки → Конфиденциальность и безопасность → Подтвердить вход / Open Anyway**.
3. При обновлении с 1.x нажми **Обновить службу…** и подтверди запрос администратора macOS. Это удалит старую службу и её права sudo; сохранённые пользовательские стратегии останутся.
4. Выбери движок и стратегию, нажми **Подключить**. Для SOCKS укажи `127.0.0.1:1080` в приложении или явно включи **Системный SOCKS-прокси**. Изменение системных настроек может потребовать подтверждение macOS. Перед пакетным режимом отключи туннельный VPN и подтверди права администратора.
5. Перед сменой движка или стратегии нажми **Отключить**. **Выход** также останавливает Darkware и восстанавливает настройки прокси; при ошибке восстановления приложение остаётся открытым и предлагает восстановить сеть.

До включения системного SOCKS прежние настройки сохраняются; восстановление выполняется при отключении и следующем запуске после аварии приложения. Изменения, которые успела внести другая программа, сохраняются. Версия 1.x не запоминала исходный прокси, поэтому перед первым подключением 2.0 проверь настройки сети.

## Стратегии и диагностика

- **Проверить** сравнивает прямое HTTPS-соединение с двумя запросами через каждый локальный SOCKS-профиль. Системные настройки не меняются. Успех подтверждает HTTPS выбранного домена; воспроизведение видео, QUIC, пакетный режим и голос Discord проверяются отдельно. Для применения найденного профиля выбери его явно.
- **Свои стратегии** принимают аргументы tpws/ByeDPI с кавычками и передают их напрямую движку; shell-выражения не исполняются. Адрес, порт, процессы и файловые опции контролирует приложение.
- В пакетном режиме кнопка **Открыть списки доменов** открывает `~/Library/Application Support/DarkwareZapret/lists`. После правки переподключись. IPSet: только домены, комплектный список IP или все IPv4.
- Из меню доступны **Журнал**, копирование отчётов и запуск **При входе**. Автозапуск открывает приложение, но не подключает его автоматически.

При проблемах отключись и используй **Восстановить сеть**, если кнопка появилась. Если приложение принудительно завершено с включённым системным SOCKS, открой его снова для восстановления настроек. В [issue](https://github.com/RoninReilly/darkware-zapret/issues) укажи версию macOS, движок, стратегию и скопированный отчёт диагностики. Перед отправкой удали личные домены и адреса.

## Сборка из исходников

Нужны macOS, Xcode Command Line Tools и Swift 6. Исходники движков закреплены в репозитории; их сборка не скачивает изменяемые upstream-ветки.

```bash
git clone https://github.com/RoninReilly/darkware-zapret.git
cd darkware-zapret
git checkout v2.0.0-beta.1
./scripts/build-engines.sh
./scripts/check-engine-presets.sh
./scripts/test-native.sh
./scripts/check-runtime.sh
./scripts/check-runtime-engines.sh
swift test
./create_app.sh v2.0.0-beta.1
```

Полный `swift test` требует модулей Swift Testing из Xcode. На установке только с CLT два скрипта `check-runtime` выше выполняют самостоятельные проверки логики и настоящих движков.
